# Phase-1 Examination Rules

## Confirmed Rules
1. Objective-type questions only.
2. Questions are randomly selected from the predefined question pool.
3. All students attempting the same examination receive the same selected question set.
4. Selected questions are presented in shuffled order.
5. Students can revisit and change answers before submission.
6. Teachers can edit or remove questions only before the examination is published.
7. No notification feature is included.
8. Examination reports can be viewed by authorized teachers and administrators.
9. Results are automatically released at the configured result-release time.
10. The teacher configures the examination duration and availability period.
11. Students can view a released result only after the configured release time; unauthorized users cannot access the result.
12. Administrator login is required before accessing administrative functions.
13. Authorized administrators can manage approved system-level settings and access permissions according to defined roles.

## Timing Fields
The examination configuration covers:
- examination duration
- availability period
- configured result-release time

No fixed numeric duration, availability window, or release delay is assumed in this handoff; those values remain configurable examination settings.

## Requirement Status
The functional requirements FR-01 through FR-24 are finalized in the Phase-1 requirements handoff. NFR-03 has a measurable 3-second target under normal load. NFR-06 retains a proposed 5-minute target and requires team approval before being treated as final.
