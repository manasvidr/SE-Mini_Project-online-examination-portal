# Phase-1 Examination Rules

## Confirmed Rules
1. Objective-type questions only.
2. Questions are randomly selected from the predefined question pool.
3. All students attempting the same examination receive the same selected question set.
4. Selected questions are presented in shuffled order.
5. Students can revisit and change answers before submission.
6. Teachers can edit or remove questions only before the examination is published.
7. No notification feature is included.
8. Examination reports can be viewed by teachers.
9. Results are automatically released at the configured result-release time.
10. The teacher configures the examination duration and availability period.
