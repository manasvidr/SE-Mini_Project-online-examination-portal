# Online Examination Portal

Software Engineering Phase-1 Mini Project — Team E6

## Project
An Online Examination Portal covering student, teacher, administrator, and supporting examination workflows.

## Phase-1 Documentation
This repository contains the Phase-1 requirements work, including functional requirements, examination rules, validation mapping, and the Requirement Traceability Matrix (RTM).

## Key Confirmed Rules
- Objective-type questions only
- Random selection from a predefined question pool
- Same selected question set for all students attempting the same examination
- Selected questions are shuffled
- Students may revisit and change answers before submission
- Teachers may edit/remove questions only before publication
- No notification feature
- Teachers may view examination reports
- Results are automatically released at the configured result-release time
- Teacher configures examination duration and availability period
